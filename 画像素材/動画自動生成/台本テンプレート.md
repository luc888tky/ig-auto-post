# 台本テンプレート（動画自動生成用）

このファイルは、週次の台本データ（`data/week*.json`）を作るときの「型」です。
他のクリエイターのショート動画で使われている、視聴維持率を上げるための構成・編集ルールを反映しています。
新しい週の台本を作るときは、このテンプレートに沿って書いてください。

## 1. 台本の基本構成（フック→本編→CTA）

1本のナレーション（`narration`）は、次の3パートで組み立てます。

1. **フック（最初の一文）**: 最初の3秒で「続きを見たい」と思わせる一文
2. **本編**: 伝えたいことを1つのメッセージに絞って説明する
3. **（任意）締めの一言**: 自然に終わる。「フォローしてね」等の直接的な呼びかけは`cta`側で扱う

### フックの5パターン（このどれかを使う）

| パターン | 型 | 例 |
|---|---|---|
| 結論先出し型 | 「実は〇〇なんです」 | 「実は電子コミックアプリって、無料で読めるジャンルがすごく幅広いんです」 |
| 問題提起型 | 「〇〇じゃないですか？」「〇〇って知ってますか？」 | 「無料キャンペーンの仕組み、知ってる？」 |
| 数字提示型 | 「〇秒で分かる〇〇」「〇つの〇〇」 | 「30秒でわかる無料の仕組み」 |
| 否定・警告型 | 「〇〇する前に知っておくべきこと」 | 「課金する前に、まずこの仕組みを知っておくとお得です」 |
| 実演・比較型 | ビフォーアフターを一文で見せる | 「雨の日って、実はじっくり読める日でもあるんです」 |

## 2. JSONスキーマ（1日分）

```json
{
  "day": 1,
  "angle": "その日のテーマ(短く)",
  "narration": "フック文から始まる1〜2文のナレーション全文",
  "images": [
    {"prompt": "1カット目の画像生成プロンプト(英語, 具体的キャラクター名や作品名は使わない)"},
    {"prompt": "2カット目の画像生成プロンプト"},
    {"prompt": "3カット目の画像生成プロンプト"}
  ],
  "telop": [
    "フック相当のテロップ(黄色で強調表示される)",
    "本編のテロップ",
    "CTA相当のテロップ(オレンジで強調表示される)"
  ],
  "bgm_mood": "lofi など bgm/ フォルダにあるムード名",
  "cta": "最後に促したい行動を1つだけ(例: プロフィールのリンクから覗いてみて)"
}
```

### ポイント

- `images` は **2〜3枚を目安**にする（1枚だけでもよいが、動画全体を通して同じ画像を見せ続けない「2秒ルール」を意識し、複数枚に分けるのを推奨）。
  1枚目=フックの情景、2枚目=本編の情景、3枚目=補足や余韻、という順番にすると自然。
- `telop` は3行を基本とする。1行目＝フック、最後の行＝CTA、として自動的に色分け表示される
  （1行目は黄色・少し大きめ、最後の行はオレンジ、間は白）。
- `narration` にキャラクター名・作品名・サービス名などの固有名詞は入れない（著作権・商標への配慮）。
- `cta` は1つの行動に絞る（保存・プロフィールへの誘導など、複数を同時に言わない）。

## 3. 編集面で反映しているルール（スクリプト側で自動対応済み）

- **2秒ルール**: `images`が複数枚あれば、動画の長さを均等に割って画像を切り替える（`assemble_video.py`が自動処理）
- **テロップの色分け**: フック（黄）とCTA（オレンジ）を目立たせる（`assemble_video.py`が自動処理）
- **テロップと音声の同期**: 台本を3〜5行程度の短いテロップに分けておくと、時間配分が自然になる

## 4. 次の週を作るときの手順

1. このテンプレートの「1日分」ブロックを7日分コピーして、`data/week{N}.json` を作る
2. 各日、フックの5パターンから1つ選んで`narration`の最初の一文を作る
3. `images`を2〜3個、場面が少しずつ変わるように書く（1カット目→2カット目で寄る、引く、切り替えるなど）
4. `telop`を3行、`cta`を1つ決める
5. GitHub Actionsの「動画自動生成」ワークフローを`week{N}.json`を指定して実行する
